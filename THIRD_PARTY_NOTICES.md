The runtime uses Python's standard library, including SQLite bindings, executor threads and OS file locking. SQLite is an external implementation used through those bindings; see its [public-domain notice](https://www.sqlite.org/copyright.html).

Building from source uses setuptools 80.9.0 and wheel 0.45.1 (MIT-licensed packaging tools); they are build dependencies, not copied into the application. CI also uses GitHub-maintained setup/checkout actions.

The synthetic binary assets follow the [Khronos glTF 2.0 specification](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html). Geometry is generated by the included tiny fixture engine; no third-party model assets are included. The specification itself is not redistributed.
